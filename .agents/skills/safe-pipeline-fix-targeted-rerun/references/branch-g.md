## 分支 G：改动本身要让**所有**产物都变时（"对照组逐像素不变"这条判据不可用）

触发：修的不是"某个皮肤读错了"，而是**每帧都要走的那段算术本身错了**——合成算子、
画布边界口径、取景规则、色彩空间。正当结果就是"所有图都该变"，于是本技能主干的第 4 步
（对照组 maxdiff=0）天生失效，用户反而会合理地质疑"那怎么保证不毁掉其余的"。

### G1：先把政策收敛成**正本里的一个函数**，否则后面全做不了

不是为了整洁，是为了验证侧能**只换函数**就渲出旧行为。
反面：探针自己重写一遍仿射/取整 = 造出第二份实现，必然漂移（真实一轮里连犯三次：
`ch` 用了旧口径的值 → 与正本产物不一致 → 虚报 32 万"实心区变化"；
改对齐时行列写反、锚点被一个杂点带偏 1 行、精搜的施加方向与打分方向反号——
每次表现都是"几百万假回退"）。

### G2：探针必须**两条保真断言**，缺一条就是在比空气

- **旧侧**：换回退役实现渲出来的东西，必须与**在盘产物逐字节相同**。
  ⚠ 退役实现要连**输入集**一起退役——旧口径对"所有节点框"取 max，新口径是"落笔框 ∪ 节点框"，
  探针若把新输入喂给退役函数，`旧=盘` 会红，而红的原因不是渲染错了。
- **新侧**：探针算出的"新"必须与**正本产物的产物逐字节相同**，否则验的是自己想象的新实现。
  （上一版只写了旧侧，`aersasi_3` 行号算歪没被发现。）

### G3：捆在一起的多个改动必须**能单独开关**

不能分开的代价是报出错误的影响面：把"找回像素"这一列同时算上
①被裁内容找回 ②极淡像素从"平方成 0"里复活，得到 **96% / 约 4320 张**；
加"只换画布不换算子"档重测，真值是 **2.0% / 约 90 张**。
**一个看起来很有发现的数字，往往是两件事混在一起的假信号。**

### G4：对齐用正本记录的**取景事实**，不要用图像配准

让正本每次产出时落 `{origin, canvas, crop}`，两版公共框的平移就是精确整数。
配准路线（实心包围盒当锚点 + 小平移精搜）天生不稳：锚点会被一个杂点带偏，
而 1px 错位在一幅细节图上恰好表现为"alpha 全同、只有轮廓 RGB 不同、密度铺满全图"——
与真回退无法区分。

### G5：判据落在"会毁图的那个量"，并且要能证明"只碰该碰的域"

| 判据 | 抓的是什么 |
|---|---|
| 离任何半透明像素 ≥2px 的实心区，可见变化 `|Δ|≥12` 必须 0 | 政策改动的正当影响域只有柔边；实心区变了才是毁图 |
| 不透明(≥250) 不得退化成半透明 | 抓"画布缩小反而新裁内容"这类**反向**伤害（本项目就是这么抓到 `baixue` 2427→2426） |
| 内容丢失必须 0（只许找回） | 新口径若号称是旧口径的超集，一旦不成立即证口径写错 |
| 分类器类判定（阈值/门控）翻转：**逐条点名 + 每条配对照图** | 换测量口径 = 换分类器；只在带标签小样本上验等于没验 |

"只碰边缘"这种声明**必须写成可测命题**（两版 `alpha∈{0,255}` 的像素逐位相同），
不是形容词——这才是回答用户"会不会毁图"的东西。

### G6：影响面用分层抽样给，不要用"筛候选"给

候选筛子本身会漏：本项目先按"rect 框有负坐标"筛，得到 244 候选 → 内容级 19 张；
实际正方向也在裁（顶点合法越框），抽样真值 ≈90 张。**"没在候选里"≠"没问题"。**

**本分支的验收**：抽样里 `实心区变化 / 不透明退化 / 内容丢失` 三列**恒为 0**；
两条保真断言逐张 `旧=盘✅ / 新=正本✅`；换入仍走第 6~7 步（脱离进程 + 完成哨兵 +
四道检查 + 派生产物增量重建）；若元数据不该变，索引重建后应当**逐字节相同**，
这本身就是"没顺手改到别的"的证据。被否证的调参（抬阈值救个例）写进常量注释，防下次再试。
