# PROJECT_STATUS.md 格式规范

此文件定义进度文档的标准格式。新建项目时可参考此模板。

## 文件结构

```markdown
# 项目名称 — 进度总结

> **生成时间**: YYYY-MM-DD
> **用途**: 跨会话对接，方便新会话快速了解项目状态

---

## 1. 项目概览

项目简介。

- **源路径**: `path/to/source`
- **规模**: N 个文件，X GB
- **格式**: 文件格式说明

---

## 2. 各部分进度

### 2.1 任务名称 ✅ 已完成

| 指标 | 数值 |
|---|---|
| 指标名 | 数值 |

**脚本**: `scripts/xxx.py`
**状态**: 完成说明

### 2.2 任务名称 ⚠️ 部分完成

| 指标 | 数值 |
|---|---|
| 指标名 | 数值 |

**问题**: 问题描述
**待解决**: 待办事项

### 2.3 任务名称 ⏳ 未处理

- 待办说明
```

## 状态标记

| 标记 | 含义 | 使用场景 |
|---|---|---|
| ✅ 已完成 | 任务成功完成 | 全量导出成功、脚本验证通过 |
| ⚠️ 警告/部分完成 | 有但非致命问题 | 部分文件失败、有已知限制 |
| ⏳ 未处理 | 尚未开始 | 待执行的任务 |

## 指标表格

标准列：`| 指标 | 数值 |`

常用指标：
- 文件数 / 导出数 / 失败数
- 总大小 / 输出大小
- 耗时
- 输出路径
- 分类数 / 模型数

## 子章节编号

使用 `### 2.X` 格式，X 为递增数字。保持与现有文档一致。
